# E2: where am I, and the debug map

Repository: 3gix-earth, branch `grunt`. Contract: `/workspace/docs/design.md` sections 3, 5 (items 1 to 3), 6, 7, 8. Builds on E1.

## What to build

1. **Geodesy** (`src/geo/`, design section 8): extend E1's module with local east-north-up axes, heading and tilt from a camera orientation in frame 4 and the orientation from heading, tilt, and position, great-circle distance, and the WGS84 check against `frames()`. Read the renderer's camera conventions (which camera axis looks forward and which is up) from `/context/3gix-renderer/crates/renderer/src/camera.rs` and the contract's pose definition, and state them in a doc comment. Tests: round trips, known headings (north, east), straight down.
2. **Ground under a point**: read how `surfaceHeight` relates height to direction from `/context/3gix-core` (`gx_core::surface`) and `/context/3gix-renderer/docs/api.md` section 6, and write `groundUnder(position)` returning the ground point and elevation, falling back to the reference ellipsoid when null. Unit tests with a mocked `surfaceHeight`.
3. **Start facing north**: the start (and any later placement) sets the orientation from heading and tilt, so the default start faces north at 45 degrees below level.
4. **Readout** and **compass** (section 5 items 1 and 2) from the `camera` event, throttled to 10 updates a second. North up and straight down move nothing but the orientation.
5. **Inspect** (section 5 item 3) from the `hit` event, in an MUI snackbar or popover.
6. **Address bar** (section 6): read on start, write while moving.
7. **Debug panel** (section 7): a settings switch and `?debug=1`; the top-down map with both markers, the line, map type control, and click to go; the 3D view mirroring the camera. The Maps key comes from config `mapsKey`. Load the Maps JavaScript API once. Find the right way to load `Map3DElement` (library `maps3d`) from Google's current documentation. Both maps update at most 5 times a second. Tests: the panel's math (the points it shows for a given pose) with the maps mocked.
8. README and design stay true.

## Done when

- `npm run ci` prints `ci ok`.
- The summary gives the commit, the camera conventions you found, how `surfaceHeight` is interpreted, and what you could not check.
