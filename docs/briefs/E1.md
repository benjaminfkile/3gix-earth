# E1: the MFE scaffold and the view

Repository: 3gix-earth, branch `grunt`. Contract: `/workspace/docs/design.md` sections 1, 2, 3. The shell that loads it is `/context/3gix-shell` (its `docs/design.md`).

## What to build

1. Vite + React 19 + TypeScript strict + MUI app, scripts `dev`, `build`, `preview`, `test`, `typecheck`, and `ci` (typecheck, tests, build, then print `ci ok`). `.gitignore` covers `node_modules`, `dist`, `.env*`, `*.pem`.
2. Dependency `3gix-renderer` from `https://github.com/benjaminfkile/3gix-renderer/releases/download/v0.1.0/3gix-renderer-0.1.0.tgz`. Exclude it from Vite's dependency prebundling so its `new URL(..., import.meta.url)` lookups of the wasm and workers stay relative to its own files.
3. `vite.config.ts`: `@module-federation/vite` as remote `gx_earth` exposing `./EarthApp` with the shared singletons of section 1; the dev server of section 2 (HTTPS when both TLS variables are set, `GX_HOST`, `GX_EARTH_PORT` default 5181, CORS for any origin, the `/hub` proxy with WebSocket upgrades, `/earth-config.json` from the environment). The remote entry is served at `/remoteEntry.js` in dev and in preview.
4. `src/config.ts`: loads `/earth-config.json` and builds the hub base, both resolved with `new URL(path, import.meta.url)` (section 2 item 3). Tests for the URL resolution, including a page on another origin.
5. `src/EarthApp.tsx` (the exposed module) and `src/main.tsx` (stand-alone page that renders it full screen): MUI theme (dark), `GxRenderer` with `controls: "none"` and the HUD off, frame 4 in one constant, the start of section 3 item 3 (place the camera with `placeOver` from latitude and longitude; facing north comes in E2, so whatever heading `placeOver` gives is fine here; set the clock to the latest local solar noon at that longitude not after now). A missing setting shows an MUI alert naming it (section 2 item 4); a renderer `error` event shows an alert with the message.
6. Minimal `src/geo/wgs84.ts`: latitude, longitude, height to a position in frame 4's axes and the unit direction, and back (design section 8), with round trip tests at the poles, the equator, and both sides of the antimeridian. Later waves extend this module.
7. Tests with the package's `Renderer` and `GxRenderer` mocked: the app passes the hub base and keys from config, places the camera at the start after `ready`, and sets the clock to the local noon (a fixed clock in the test).
8. `README.md`: what this is, the environment variables, how to run it alone and inside `3gix-shell`.

## Done when

- `npm run ci` prints `ci ok`.
- The summary gives the commit, the versions used, and what you could not check (WebGPU drawing, the real hub, the shell loading it).
