# E5: search and bookmarks

Repository: 3gix-earth, branch `grunt`. Contract: `/workspace/docs/design.md` section 5 items 4 and 7. Builds on E4.

## What to build

1. Search box (MUI Autocomplete) at the top of the view with Google Places autocomplete (Places API, New, through the Maps JavaScript API `places` library: `AutocompleteSuggestion` with a session token, then `Place.fetchFields` for location and viewport). Debounced, keyboard navigable, works on phones.
2. Choosing a result flies the camera there (animated, about 2 s; up, over, and down for long distances), framed so the place's viewport fills the view at 45 degrees tilt facing north; a point without a viewport gets 2 km above the ground.
3. Bookmarks (section 5 item 7): save the current view with a name, list, go to (same flight), rename, delete, in local storage.
4. Typing in the search box never moves the camera (E4 item 5).
5. Unit tests with the Places library mocked: suggestions shown, selection fetches fields and starts the flight to the right framing; the framing math; bookmarks storage round trip.
