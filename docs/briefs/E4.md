# E4: Fly mode and the mode toggle

Repository: 3gix-earth, branch `grunt`. Contract: `/workspace/docs/design.md` section 4 (common rules and Fly mode). Builds on E3.

## What to build

1. Fly mode for keyboard and mouse: the keys of section 4 through `setFlightInput`, mouse drag or pointer lock to look, Shift to boost, `setSpeed` from the height above the ground.
2. Fly mode for touch: an MUI styled virtual joystick at the lower left that moves, drag anywhere else to look, a boost button. Shown only on touch devices or narrow screens while in Fly mode.
3. Ground clearance in Fly mode: when the pose comes within 2 m of the ground, lift it with `setCamera`.
4. The mode toggle in the toolbar (section 4), remembered in local storage. Switching never moves the camera and clears any flight input.
5. Keyboard input only while the view has focus; nothing leaks to the shell's page or other inputs (the search box typing must not move the camera).
6. Unit tests: key state to flight input, joystick vector to flight input, speed from height, the toggle clears input.
